# Frontend UI Plans

## File nào dùng để làm gì

- `master-test-plan.vi.md`: master rulebook, bắt buộc đọc trước khi test thủ công.
- `execution-checklist.vi.md`: checklist điều phối thực thi theo đợt.
- `remaining-test-plan.vi.md`: kế hoạch xử lý các case còn mở.
- `test-finish-plan.vi.md`: kế hoạch chốt nốt phần còn lại để sign-off.
- `next-5-sessions-plan.vi.md`: kế hoạch ngắn hạn cho các session test tiếp theo.

## Thứ tự đọc khuyến nghị

1. `master-test-plan.vi.md`
2. Runbook batch tương ứng trong `qa/runbooks/frontend-ui/`
3. Một trong các file execution/remaining nếu đang follow một đợt test cụ thể

## Lưu ý

Các file trong thư mục này là tài liệu điều phối.
Chúng không thay thế checklist gốc ở `qa/checklists/frontend-ui/testfrontendui.md`.
