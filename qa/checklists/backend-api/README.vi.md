# Backend API Checklist

Checklist xuong song cua backend nam tai:

- `qa/checklists/backend-api/test.md`
- Ban PDF tham chieu: `qa/checklists/backend-api/test.pdf`
- Anh minh hoa login: `qa/checklists/backend-api/test-login.webp`
- Traceability matrix: `qa/checklists/backend-api/traceability-matrix.vi.md`

Tu checklist nay, QA can doi chieu them:

- `qa/plans/backend-api/master-test-plan.vi.md` cho luat thuc thi tong the
- `qa/plans/backend-api/execution-checklist.vi.md` va `qa/plans/backend-api/execution-checklist-dot2.vi.md` cho dot dang chay
- `qa/runbooks/backend-api/` cho batch chay thuc te
- `qa/playbooks/backend-api-sop-mapping.vi.md` de biet SOP/playbook phai doc truoc khi ket luan bug
- `school-mgmt/backend/test/` cho E2E/Jest chinh thuc
- `school-mgmt/backend/scripts/test-*.js` va `test-*.ts` cho workflow scripts theo module
- `qa/playbooks/README.vi.md` khi luong co nghiep vu tai chinh, payroll, ads, RBAC, reconciliation

Checklist backend da duoc dua ve `qa/` de dong nhat voi hub kiem thu.
Source code test runner van nam o `school-mgmt/backend/`.
