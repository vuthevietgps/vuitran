1. Doc so tay cua vi tri de hieu muc tieu, man hinh, luong thao tac va quy tac phoi hop.
2. Dung checklist cung vai tro de theo doi tien do trien khai va van hanh thuc te.
3. Khi can anh minh hoa, kich ban demo hoac bang route chi tiet, mo them cac tai lieu nguon duoc lien ket trong tung so tay.
