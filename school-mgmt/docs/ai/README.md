# AI Docs

Thu muc nay la noi dat tai lieu thiet ke AI chatbot va AI Assistant Core cho ERP.

## Tai lieu chinh

- [AI Assistant Core Blueprint](./ai-assistant-core-blueprint.md): kien truc core dung chung, capability, situation, tool registry, policy va migration tu Director AI.
- [AI ERP Assistant Code Organization Review](./ai-erp-assistant-code-organization-review.md): danh gia to chuc code nhung AI vao ERP, phan loai tinh huong cung/lap lai va long/mem de tiet kiem token.
- [AI Chatbot Situation And Permission Matrix](./ai-chatbot-situation-permission-matrix.md): ma tran assistant type, role, tinh huong, API va quyen doc/ghi.
- [AI Feedback Improvement Loop](./ai-feedback-improvement-loop.md): cach luu hoi thoai chua thoa dang va chia sub-agent de nang cap tinh huong, tool, policy va eval.
- [OPS AI Conversation Corpus](./ops-ai-conversation-corpus.md): cach to chuc hoi thoai cua tro ly van hanh thanh corpus review/eval ma khong nap raw chat vao prompt mac dinh.
- [Operational Knowledge Base](./operational-knowledge-base.md): tong hop tri thuc van hanh hien co va huong tach role-scoped knowledge de tiet kiem token, prompt va tang bao mat.
- [AI Role Situation API Coverage](./ai-role-situation-api-coverage.md): ma tran tinh huong theo tung user type, ERP API/tool tuong ung va coverage OK/PARTIAL/MISSING.
- [Management Situation Upgrade](./management-situation-upgrade.md): chuan mo rong cac packet quan tri lap lai, cach AI xu ly de tiet kiem token va nang chat luong cau tra loi.
- [Director AI ERP API Catalog](./director-ai-erp-api-catalog.md): catalog tool runtime hien tai cho chatbot giam doc.
- [Teacher AI Situations Guide](./teacher-ai-situations-guide.md): tinh huong AI cho giao vien, giao vien review va huong dan su dung `/ai/chat`.
- [Sale AI Situations Guide](./sale-ai-situations-guide.md): tinh huong AI cho sale, cham soc lead, order, hoc thu/test, hoa hong va huong dan su dung `/ai/chat`.
